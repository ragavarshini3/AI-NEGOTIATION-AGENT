# AI Negotiation Agent

## Overview

AI Negotiation Agent is an intelligent multi-agent system designed to simulate and automate negotiation processes between autonomous agents. The project leverages Artificial Intelligence techniques to model negotiation strategies, decision-making, offer generation, and agreement optimization.

The system demonstrates how AI agents can interact, negotiate terms, evaluate proposals, and reach mutually beneficial agreements in dynamic environments.

---

## Features

* 🤖 Autonomous AI negotiation agents
* 💬 Multi-round negotiation conversations
* 📊 Dynamic offer evaluation and scoring
* 🎯 Goal-oriented decision making
* 🔄 Adaptive negotiation strategies
* 📈 Performance and negotiation analytics
* 🧠 AI-driven reasoning for counteroffers
* ⚡ Real-time negotiation simulation

## How It Works

1. A negotiation scenario is initialized.
2. Buyer and seller agents receive objectives and constraints.
3. Agents exchange offers and counteroffers.
4. Each agent evaluates incoming proposals.
5. Strategies are adjusted based on negotiation history.
6. Negotiation concludes when:

   * An agreement is reached, or
   * Maximum negotiation rounds are exceeded.

## Installation

### Clone the Repository

```bash
git clone https://github.com/ragavarshini3/AI-NEGOTIATION-AGENT.git
cd AI-NEGOTIATION-AGENT
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```
